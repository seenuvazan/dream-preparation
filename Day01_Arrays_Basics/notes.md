Day 01: Arrays - Basics 

Arrays store elements of the same data type in contiguous (back-to-back) memory locations. 
Because memory is sequential, accessing any element using an index is instantaneous.

 Address formula: `Address(A[i]) = Base_Address + (i * size_of_element)`
 Direct Index Access: O(1) time
 Fixed size: Traditional arrays cannot grow dynamically without allocating a new block in heap memory.
